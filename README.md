# PlasmaWallShift

WallShift is a KDE Plasma 6 wallpaper plugin for rotating local wallpaper folders with animated transitions.

## Features

- Multiple local wallpaper folders, one folder per line.
- Rotation order: name, modified time, or random non-repeating cycle.
- Configurable rotation interval.
- Plasma image positioning modes.
- Animated transitions include grow, outer, wave, fade and wipe.

## Install

```sh
kpackagetool6 --type Plasma/Wallpaper --install org.wallshift.wallpaper
```

For updates:

```sh
kpackagetool6 --type Plasma/Wallpaper --upgrade org.wallshift.wallpaper
```
