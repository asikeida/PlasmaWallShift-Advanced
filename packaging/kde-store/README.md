## Short description

Rotate local wallpaper folders with editable shader transitions and cubic Bézier timing curves for KDE Plasma 6.

## Description

WallShift Advanced rotates images from one or more local folders and adds ten configurable transitions, an interactive cubic Bézier curve editor, per-effect controls, a random transition pool, double-buffered image loading, and latest-request queuing.

Radial effects can start from a random point, the center, a custom point, or the global mouse position. Global cursor origin is optional and requires `kdotool`; all other features work without it.

The package uses the independent plugin ID `io.github.asikeida.wallshiftadvanced` and can coexist with the original WallShift plugin.
