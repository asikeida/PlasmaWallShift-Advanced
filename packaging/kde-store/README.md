## Short description

Rotate local image and video wallpapers with editable shader transitions and cubic Bézier timing curves for KDE Plasma 6.

## Description

WallShift Advanced rotates images and opt-in local videos from one or more folders. It adds ten configurable transitions, an interactive cubic Bézier curve editor, per-effect controls, a random transition pool, double-buffered media loading, and latest-request queuing. Videos are muted, play once, and then advance automatically. Video scanning is disabled by default.

Radial effects can start from a random point, the center, a custom point, or the global mouse position. Global cursor origin is optional and requires `kdotool`; all other features work without it.

The package uses the independent plugin ID `io.github.asikeida.wallshiftadvanced` and can coexist with the original WallShift plugin. Qt Multimedia and suitable system codecs are required for video playback. This KDE Store package intentionally contains only the wallpaper plugin; the optional `Meta+F5` companion is available from the GitHub and Arch packages.
